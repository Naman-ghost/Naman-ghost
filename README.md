### 🧠 Featured Project
**[VolEdge — Volatility Surface Arbitrage Engine](https://github.com/Naman-ghost)**
An end-to-end options research pipeline: recovers implied volatility from option prices via Brent's method, fits smoothing-spline volatility smiles, flags statistically significant mispricings, and backtests a systematic strategy under realistic NSE transaction costs. Built in Python (NumPy, SciPy, Pandas).
